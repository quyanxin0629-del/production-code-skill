## 复现方式

在仓库根目录安装 requirements-dev.txt 后执行 `python scripts/validate.py`。脚本从发布的 Markdown 直接提取并验证关键模式，批处理测试在 tests/test_batch.py 中。依赖仅用于验证，安装 Skill 本身不需要安装 Python 包。

## 行为检查内容

- CNY 精确文本、范围、非法精度、非有限值与类型拒绝。
- 最小单位分摊守恒、非负与稳定尾差。
- aware UTC 要求、DST 不存在 / 重复时间、23 / 25 小时日历边界。
- JSON 重复键、NaN / Infinity 和指数导致的 float 溢出；字符串大整数保真。
- 严格数量类型、空明细、重复 SKU、未知字段。
- 并发请求 ContextVar 隔离、异常后恢复、无效关联 ID 与线程上下文复制。
- 从最终 Python 参考文件直接提取批处理模板执行：空输入、None 输入、10 万项输入下任务 / 缓冲 / 并发有界，处理失败、源失败、单项与总超时、上游取消、子任务自行取消、非法配置、退出后无遗留任务。

## 根据审查修正

1. JSON parse_constant 不涵盖 1e400 的默认 float 溢出，已增加有限数值检查。
2. Expand / Contract 迁移明确旧列权威期、旧写入者退出、重新回填与回滚同步，避免旧实例写入使新列陈旧。
3. 批处理监督显式处理子任务 CancelledError，避免把 worker 自行退出当作正常完成；保留协作取消与清理预算的边界。
